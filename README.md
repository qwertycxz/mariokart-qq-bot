# 马车比赛细则

## 一、比赛编制

1. 比赛设四支队伍，固定名称为：红队、蓝队、黄队、绿队。
2. 每支队伍由赛事组织者登记参赛成员。成员可以被移入其他队伍，但同一名成员同时只能属于一支队伍。
3. 本细则中的“本局”指从执行一次 `/抽` 开始，到本轮车辆和车手状态确定为止的完整抽取流程。

## 二、车辆与车手抽取

1. 每局开始时，系统为四支队伍分别随机抽取一名车手和一台车辆。
2. 四支队伍抽到的车手互不重复，抽到的车辆也互不重复。
3. 车手和车辆分别独立抽取，因此车辆和车手之间不要求固定配套。
4. 初次抽取完成后，系统会展示每队的车手、车辆、当前积分和剩余重抽次数。

## 三、积分与重抽费用

1. 每局开始时，每支队伍获得三次重抽机会。
2. 重抽机会属于提出重抽的队伍，可以用于重抽自己，也可以用于重抽其他队伍。
3. 每次成功重抽会同时重新抽取目标队伍的车手和车辆，并消耗提出队伍的一次机会。
4. 重抽费用按照提出队伍当前积分的排名确定：

    | 当前积分排名 | 每次重抽费用 |
    | ------------ | -----------: |
    | 第一名       |        15 分 |
    | 第二名       |        10 分 |
    | 第三名       |         5 分 |
    | 第四名       |         3 分 |

5. 费用以发起本次投票时的积分排名为准。同一轮投票中，即使多个目标队伍同时通过重抽，费用也按同一个单价计算。
6. 积分相同时采用竞赛排名：同分队伍使用相同的排名和费用，后续排名按占用的名次顺延。例如两队并列第一名时，两队费用均为 15 分，下一队按第三名计费，费用为 5 分。
7. 成功重抽后，从提出队伍的积分中扣除“成功重抽的目标队伍数量 × 单次费用”。积分不足时不得完成该次重抽。
8. 本细则只规定重抽费用；比赛名次如何产生积分，由赛事组织者另行公布。

## 四、重抽投票

1. 当某队仍有重抽机会且能支付至少一次当前费用时，系统开启该队的重抽投票。
2. 每次投票持续约 60 秒。投票不可撤回。
3. 只有已经登记在提出队伍中的成员，其投票才会被计入该队的票数。
4. 每名成员对同一个目标队伍至多计一票；一名成员可以同时支持多个目标队伍。
5. 对每个目标队伍分别计算是否通过：获得支持的成员数必须严格超过提出队伍登记成员总数的一半。
6. 一次投票可以同时通过多个目标队伍。每通过一个目标队伍，消耗提出队伍的一次重抽机会，并重新抽取该目标队伍的车手和车辆。

## 五、投票失败与机会清零

1. 本次投票的全部通过目标数量必须同时满足以下条件：
    - 不超过提出队伍的剩余重抽次数；
    - 按当前单价计算的总费用不超过提出队伍当前积分。
2. 如果任一条件不满足，本次投票不执行任何重抽，提出队伍剩余的重抽机会全部清零。
3. 如果没有任何目标队伍获得过半支持，则不发生重抽，也不扣除积分或重抽机会。
4. 某队重抽机会用尽后，本局不再发起该队的投票。

## 六、重抽后的判定

1. 重抽只影响通过投票的目标队伍；未通过投票的队伍保留原车手和车辆。
2. 每次重抽完成后，系统会重新展示四队的完整状态。
3. 重抽后的车辆和车手仍须分别保持四队互不重复。
4. 当所有队伍都没有可执行的重抽投票时，本轮抽取流程结束，随后按赛事安排进行正式比赛。

## 七、Bot 操作

以下命令由群主执行：

| 命令                                      | 作用                                             |
| ----------------------------------------- | ------------------------------------------------ |
| `/红 @成员`                               | 将成员加入红队；若该成员已在红队，则将其移出红队 |
| `/蓝 @成员`                               | 将成员加入或移出蓝队                             |
| `/黄 @成员`                               | 将成员加入或移出黄队                             |
| `/绿 @成员`                               | 将成员加入或移出绿队                             |
| `/红`、`/蓝`、`/黄`、`/绿`                | 查看对应队伍成员名单                             |
| `/分 红队积分 蓝队积分 黄队积分 绿队积分` | 按红、蓝、黄、绿的顺序增加积分                   |
| `/抽`                                     | 开始一局新的随机抽取，并将四队重抽机会重置为三次 |

### 操作注意

1. `/抽` 执行后，在当前抽取和投票流程结束前再次执行不会生效。
2. `/分` 使用整数参数，例如 `/分 15 10 5 3`；参数顺序固定为红、蓝、黄、绿。
3. 队伍成员登记应在执行 `/抽` 前完成，否则该成员无法参与对应队伍的投票。
4. 车辆、车手、积分和重抽结果以 Bot 最后发布的比赛状态为准。
